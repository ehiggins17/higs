# Website version history

Every change to the AAUW Ann Arbor branch website (aauw-aami.org), kept in order.

- `site/wp-content/` — plugins and theme files that run on the live WordPress site. A push here deploys to Hostinger.
- `aauw-aami/redirects/` — rules that send old annarbor-mi.aauw.net addresses to the new site.
- `aauw-aami/old-files/` — documents carried over from the old site.
- `dist/` — plugin zips ready to upload.
- `docs/ACCESS.md` — every way into the site and what each one is for.
