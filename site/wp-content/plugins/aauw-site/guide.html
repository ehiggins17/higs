This site works the same way as the AAUW-hosted site you are used to: log in, pick something from the left menu, make the change, and click Update or Publish. Nothing is saved until you do.

Add or change a program

  1. Click Programs, then Add New (or click an existing program to change it).
  2. Type the program title at the top.
  3. In Program Information, choose the Date. Fill in the time and the speaker line if you have them.
  4. Type the full description in the large box.
  5. On the right, tick a Program Type and set a Featured Image (the photo).
  6. Click Publish.

That is all. The homepage card, the calendar on the Programs page, and the Activities menu pick it up on their own. When the date passes, the site moves on to the next program by itself.

Edit a page

  1. Click Pages. Find the page and click Edit.
  2. Change the text in the large box. Use the toolbar for bold, lists, and links, the same as in Word.
  3. The Page Header box holds the small label, headline, and intro shown at the top of the page.
  4. Click Update.

Made a mistake? Open the page, find Revisions in the Publish box, and restore an earlier version.

Add a photo or a PDF

  1. Click Media, then Add New, and choose the file from your computer.
  2. To place it on a page: edit the page, put the cursor where it should go, click Add Media, choose the file, and click Insert into page.
  3. To swap a PDF for a newer one and keep the same link, open it in Media and use Replace media.

Add a new page to the menu

  1. Create the page under Pages, then Add New, and publish it.
  2. Go to Appearance, then Menus. Tick the page on the left and click Add to Menu.
  3. Drag it under the section it belongs to (About, Activities, and so on) and click Save Menu.

The short line under each menu link is the item's Description. If you do not see that box, open Screen Options at the top right and tick Description.

Change the phone number, address, or links

Go to Site Settings. These appear on every page, so you only change them once.

Messages from the website

Notes sent through the Contact and Join forms are emailed to the address in Site Settings and are also kept under Messages.

Who can do what

  • Editor: add and edit programs, pages, photos, and PDFs.
  • Super Editor: everything an Editor can do, plus menus and Site Settings.
